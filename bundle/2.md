The Ralph pattern runs AI coding agents in a loop until a goal is reached.
Each iteration spawns a fresh agent instance with no memory of previous passes.
State persists externally through a task status file and a progress log shared across iterations.
This deliberate amnesia is a core architectural property of the pattern.
Each iteration picks and implements exactly one task before stopping for verification.
This one-task discipline is a designed constraint, not a limitation.
It mirrors a single mutation per generation in natural selection.
After implementation, the iteration must verify its own output through automated checks.
These feedback gates are the selection pressure that drives improvement.
Without verification, errors compound across iterations and the loop degrades.
The agent does not remember past work, but the repository does through its history.
The loop treats LLMs as a new kind of programmable computer.
You program it with a goal, a state file, and selection pressure rather than instructions.
The loop runs until the goal is reached and then stops.
Software evolves through repeated passes of generation and selection.
