description: Summary of the LLM Wiki pattern and the Open Knowledge Format specification.

The [Open Knowledge Format][okf-spec] (OKF) is a vendor-neutral specification that formalizes the LLM Wiki pattern into a portable, interoperable knowledge format.

A bundle is a directory of markdown files with YAML frontmatter, readable by humans and agents without bespoke tooling.

Each concept document requires a type field.

Optional fields include title, description, resource, tags, and timestamp.

Cross-links between concepts form a relationship graph.

Reserved files (index.md, log.md) provide directory listing and change history.

The [LLM Wiki][llm-wiki] pattern, described by Andrej Karpathy, replaces query-time retrieval with a persistent, LLM-maintained knowledge base.

An agent ingests sources, extracts key information, and incrementally builds a wiki, updating pages, cross-referencing concepts, and logging changes.

The human curates sources and asks questions.

The LLM handles the bookkeeping that causes humans to abandon wikis.

[Google Cloud adopted OKF][google-cloud-blog] as the interchange format for their Knowledge Catalog.

The format is designed to be produced and consumed independently, surviving across tools and organizations.
